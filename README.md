# YouTube Shorts Bot

Автоматически создаёт вертикальный Short с русским фактом, озвучкой и публикует его на YouTube.

## Что уже автоматизировано

- случайная тема из русской Википедии;
- русский AI TTS через edge-tts;
- вертикальное видео 1080x1920;
- заголовок, описание и хэштеги;
- публикация через YouTube Data API;
- запуск каждый день в GitHub Actions;
- ручной запуск через Actions -> Daily YouTube Short -> Run workflow.

## Один обязательный ручной шаг

GitHub Actions не может сам получить первый OAuth-доступ к твоему YouTube без твоего подтверждения.

Нужно один раз получить YouTube OAuth token и сохранить его в GitHub Secrets как:

YOUTUBE_TOKEN_JSON

После этого ежедневная публикация выполняется автоматически.

Важно: этот проект не хранит пароль от Google/YouTube в коде.
