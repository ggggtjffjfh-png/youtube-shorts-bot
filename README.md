# YouTube Shorts Bot

Бот автоматически создаёт готовый вертикальный Short и складывает его в **GitHub Actions Artifacts**.

## Что делает

- каждый день запускается автоматически;
- берёт случайную тему из русской Википедии;
- пишет короткий текст;
- генерирует русскую озвучку;
- создаёт видео 1080x1920;
- сохраняет готовый MP4 как Artifact;
- **ничего не публикует на YouTube**.

## Как получить видео

1. Открой репозиторий.
2. Перейди в **Actions**.
3. Выбери **Generate YouTube Short**.
4. Нажми **Run workflow** для запуска вручную.
5. После завершения открой запуск.
6. Внизу страницы найди **Artifacts**.
7. Скачай архив с MP4.

Автоматический запуск происходит каждый день.

Артефакты хранятся 30 дней.
